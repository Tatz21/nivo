# Feature Catalogue — Nivó

## P0 — Required for launch

### Brand website
- Responsive homepage.
- About and company history since 2020.
- Education service pages.
- Professional courses pages.
- HR and recruitment pages.
- Contact and enquiry forms.
- FAQ, privacy and terms pages.
- Responsive navigation and footer.

### Signature motion
- Custom desktop cursor.
- Cursor ring and dot.
- Restrained cursor glow/trail.
- Cursor-aware background light.
- Black-hole-inspired hero.
- Animated gradient/particle backgrounds.
- Magnetic CTA buttons on fine pointers.
- Selective hover/scroll reveals.
- Reduced-motion and mobile fallbacks.

### SEO
- Page titles/descriptions.
- Canonical URLs.
- Open Graph metadata.
- XML sitemap.
- Robots.txt.
- Structured data where applicable.
- Correct status codes and redirects.
- Private route noindex controls.
- Image and performance optimisation.

### Enquiries
- Education/course enquiries.
- Employer recruitment requirements.
- Candidate submissions.
- General contact.
- Validation, spam controls and confirmation states.

### Resume Studio
- Landing page and template gallery.
- Manual resume creation.
- PDF/DOCX import.
- Editable extraction review.
- Structured resume data.
- Multiple templates.
- Live preview.
- Section editing/reordering.
- Secure save/reopen/delete.
- PDF export.

## P1 — Quality and polish
- More resume templates.
- Improved parser support for common resume layouts.
- Autosave with visible status.
- Duplicate resume.
- Template preview comparisons.
- Better mobile editor flow.
- Email notification integration.
- Analytics events without personal content.
- Visual regression tests.

## P2 — Only after explicit approval
- AI-assisted resume writing.
- OCR for scanned PDFs.
- Cover letter generation.
- Paid premium templates.
- Course payments.
- Job board.
- Applicant tracking.
- General accounts/dashboards.
- LMS or video classes.

P2 items are not part of the initial build and must not be added by assumption.
